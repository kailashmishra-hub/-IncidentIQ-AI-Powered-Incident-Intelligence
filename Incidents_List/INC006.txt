Incident ID: INC006

Title: Application Log in issue

Description:
Multiple users reported being unable to log in to the application.
Despite entering valid credentials, the system returned an "Invalid Username or Password" error message.

Investigation:
Analysis of the authentication service logs indicated intermittent failures in establishing a connection to the database.
The authentication service relies on the identity database to validate user credentials, and these connection issues impacted the login process.

Root Cause:
The database server hosting the identity database experienced downtime due to a network connectivity issue.

Resolution:
The database server was restarted and network connectivity was restored.
Once the service was fully operational, users were able to log in successfully without further issues.
