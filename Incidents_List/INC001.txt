Incident ID: INC001

Title: Users unable to login to application

Description:
Several users reported that they were unable to login to the application.
When entering valid credentials, the system displayed an "Invalid Username or Password" error.

Investigation:
The authentication service logs showed that the database connection was failing intermittently.
The user authentication service depends on the identity database to validate credentials.

Root Cause:
The database server hosting the identity database was down due to a network connectivity issue.

Resolution:
The database server was restarted and the network connection was restored.
After the service was brought back online, users were able to login successfully.
