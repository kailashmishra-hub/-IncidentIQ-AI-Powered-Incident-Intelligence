Incident ID: INC004

Title: Password reset emails not received

Description:
Users reported that they were not receiving password reset emails after requesting a reset from the login page.

Investigation:
Email server logs showed that the application was sending requests to the mail service, but the emails were being blocked.

Root Cause:
The email server spam filter was incorrectly marking password reset emails as spam.

Resolution:
Spam filter rules were updated and email delivery resumed successfully.
